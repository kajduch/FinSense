# FinSense Web — Веб-платформа финансовой аналитики и ИИ-советов

**FinSense Web** (ветка `web-patch2`) — это интерактивный веб-сервис для глубокого анализа банковских выписок (PDF) с наглядными дашбордами, интеграцией с локальными языковыми моделями через **Ollama** и персонализированными финансовыми рекомендациями.

> 💡 **Ищете Telegram-бота?**  
> Telegram-версия бота FinSense находится в ветке [`main`](https://github.com/kajduch/FinBalance/tree/main).

---

## 🌟 Возможности веб-версии

- 📄 **Drag-and-Drop загрузка выписок**: быстрая загрузка PDF-выписок прямо через браузер.
- 🎯 **Персонализированный запрос к ИИ**: перед анализом вы можете сформулировать конкретный вопрос или задачу (например: *«на какие подписки уходит больше всего денег?»*, *«как снизить расходы на кафе на 15%?»*).
- 📊 **Интерактивные дашборды (ApexCharts)**:
  - Динамика расходов по категориям с удобными вкладками и переключателями.
  - График динамики изменения баланса с фильтрами.
  - Аналитика по крупнейшим получателям (Топ мерчантов / магазинов).
- 🧠 **Автономный локальный ИИ**:
  - Анализ транзакций через локальную LLM (Ollama, модель `qwen3:8b`).
  - Гарантия приватности ваших финансовых данных — выписки обрабатываются локально без отправки на сторонние серверы.
  - Умные блоки рекомендаций прямо на странице аналитики.
- ✈️ **Связка с Telegram**: кнопка быстрого перехода в Telegram-бота прямо из навигационного меню сайта.

## 🛠 Стек технологий

- **Frontend**:
  - HTML5, CSS3 (современная тёмная тема, glassmorphism, анимации).
  - Vanilla JavaScript (ES6+), асинхронные запросы (Fetch API).
  - **ApexCharts** — интерактивные графики и визуализация финансовых потоков.
- **Backend**:
  - **FastAPI** — высокопроизводительный REST API бэкенд.
  - **Uvicorn** — ASGI-сервер.
  - **PyMuPDF (fitz)** — извлечение текстового слоя из PDF-выписок.
  - **Pydantic** — валидация схем данных.
- **AI & LLM**:
  - **Ollama** (`qwen3:8b`) — локальная нейросеть для классификации транзакций и генерации советов.

## 🚀 Установка и запуск

### 1. Предварительные требования
- Установленный **Python 3.10+**
- Установленный и запущенный **Ollama** с загруженной моделью:
  ```bash
  ollama pull qwen3:8b
  ollama run qwen3:8b
  ```

### 2. Клонирование ветки `web-patch2`
```bash
git clone -b web-patch2 https://github.com/kajduch/FinBalance.git
cd FinBalance
```

### 3. Установка зависимостей бэкенда
```bash
python -m venv venv
# Активация окружения:
source venv/bin/activate  # Для Linux/macOS
# или venv\Scripts\activate для Windows
# или source venv/bin/activate.fish для fish

pip install fastapi uvicorn pymupdf requests pydantic python-multipart
```

### 4. Запуск

#### Вариант А: Быстрый запуск на Windows
В папке `skibidi/` есть готовый скрипт:
```cmd
skibidi\start.bat
```
*(Скрипт автоматически поднимет AI-сервер, FastAPI бэкенд и локальный HTTP-сервер для фронтенда)*.

#### Вариант Б: Запуск на Linux / macOS
Откройте терминал и запустите сервисы:

1. **FastAPI бэкенд** (порт 8000):
   ```bash
   cd skibidi/back
   uvicorn server:app --reload --port 8000
   ```

2. **Фронтенд** (порт 5500):
   ```bash
   cd skibidi/front
   python -m http.server 5500
   ```

3. Откройте в браузере: **`http://localhost:5500`**

## 📂 Структура каталогов веб-версии

```
skibidi/
├── back/                      # Бэкенд
│   ├── ai/                    # Модули ИИ
│   │   ├── aiassistant.py     # Логика генерации финансовых советов
│   │   ├── aiparser.py        # Парсинг текста выписки нейросетью
│   │   ├── ollamacli.py       # Клиент взаимодействия с Ollama API
│   │   └── schemas.py         # Pydantic схемы ответов
│   ├── parser.py              # Извлечение текста из PDF через PyMuPDF
│   └── server.py              # FastAPI сервер (эндпоинт /upload)
├── front/                     # Фронтенд
│   ├── index.html             # Главная страница (загрузка файла и ввод запроса)
│   ├── result.html            # Страница с дашбордами и аналитикой
│   ├── script.js              # Логика загрузки и отправки на бэкенд
│   ├── result.js              # Инициализация графиков ApexCharts
│   └── assets / svg           # Иконки и фоновые изображения
├── start.bat                  # Скрипт запуска для Windows
└── stop.bat                   # Скрипт остановки процессов
```
