FinSense — это Telegram-бот для глубокого финансового анализа банковских выписок (PDF и CSV) с генерацией наглядной инфографики и персональными рекомендациями на базе ИИ.

## Основные возможности

- 📄 **Анализ выписок:** Автоматический парсинг выписок основных банков в форматах CSV и PDF.
- 📊 **Наглядная инфографика в чате:**
  - Donut-диаграмма структуры расходов по категориям с удобной легендой.
  - График динамики изменения баланса во времени.
  - Топ-5 крупнейших платежей организациям.
  - Топ-5 крупнейших переводов людям.
- 💡 **ИИ-советник по оптимизации бюджета:** Персонализированные рекомендации по сокращению необязательных расходов без канцелярщины.
- 🎯 **Калькулятор целей накопления:** Интерактивный диалог с ИИ для расчёта реалистичных сроков накопления на основе свободных денег и оптимизации бюджета.

## Стек технологий

- **Python 3.10+**
- **aiogram 3** — асинхронный фреймворк для Telegram Bot API
- **pandas, pdfplumber** — обработка табличных данных и парсинг PDF
- **matplotlib** — генерация визуализаций и инфографики прямо в чат
- **OpenAI-compatible / Gemini API** — интеллектуальный анализ и финансовые рекомендации

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/kajduch/FinBalance.git
cd FinBalance
```

### 2. Настройка виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate  # Для bash/zsh
# или source venv/bin/activate.fish для fish
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Заполните `.env`:
- `BOT_TOKEN` — токен вашего Telegram-бота от [@BotFather](https://t.me/BotFather).
- `GEMINI_API_KEY` — API-ключ для доступа к нейросети.
- `PROXY_BASE_URL` — адрес API эндпоинта (например, `https://ai.starimg.ru/v1/chat/completions` или официальный Google/OpenAI).

### 5. Запуск бота
```bash
python bot.py
```

## 🌐 Веб-версия FinSense (ветка `web-patch2`)

Помимо Telegram-бота, в репозитории доступна автономная веб-версия сервиса (разработанная в ветке `web-patch2`), позволяющая проводить детальный анализ через браузер.

### Основные возможности веб-версии:
- 🖥 **Современный UI**: тёмная тема в стиле неоморфизма, адаптивный интерфейс и анимации.
- 📂 **Drag-and-Drop загрузка**: быстрая загрузка банковских выписок (PDF / CSV) прямо в окно браузера.
- 💬 **Персонализированный ИИ-запрос**: возможность сформулировать задачу перед анализом (например, *«найти скрытые подписки»* или *«составить план экономии»*).
- 📊 **Интерактивные диаграммы ApexCharts**:
  - Детальные графики трат по категориям с возможностью фильтрации и переключения вкладок.
  - График динамики изменения баланса.
  - Топ мерчантов и получателей платежей.
- 💡 **Умные карточки рекомендаций**: выводы нейросети отображаются в удобных блоках прямо над аналитикой.
- ✈️ **Интеграция с ботом**: кнопка быстрого перехода в Telegram-бота из шапки сайта.

### Стек технологий веб-версии:
- **Frontend**: HTML5, CSS3, JavaScript (ES6+), ApexCharts CDN.
- **Backend**: FastAPI, Uvicorn, Python.
- **AI Engine**: Локальные языковые модели через Ollama.

### Как запустить веб-версию:
```bash
# Переключиться на ветку веб-версии
git checkout web-patch2

# Запуск на Windows (в один клик):
skibidi\start.bat

# Запуск на Linux / macOS:
# 1. AI-клиент Ollama:
python skibidi/back/ai/ollamacli.py

# 2. FastAPI бэкенд:
cd skibidi/back && uvicorn server:app --port 8000 --reload

# 3. Локальный сервер фронтенда:
python -m http.server 5500 --directory skibidi/front
```
После этого интерфейс доступен в браузере по адресу `http://localhost:5500`.
